## Esoterica Engine

Infrastructure ported into `src/Editor/`, `src/Core/TypeSystem/`, and the editor tooling: the tool
framework, the type system and property grid, the undo stack, and the reflection code generator.
Algorithms and architecture were reimplemented against Tucano's own types; no files are used
verbatim. The 20 files that derive from it say so in their header — `grep -rl "Derived from
Esoterica" src Tools` lists them.

Source: <https://github.com/BobbyAnguelov/Esoterica>
